# Parkinson’s Clinical Learning Resource

An English-language static educational website about Parkinson’s disease for medical and nursing students and healthcare professionals. It is built with HTML, CSS, and JavaScript, with no runtime framework or external package dependencies.

## Run locally

1. Open `index.html` in a modern browser, or serve the project directory with a static file server.
2. If Python is available, run `python -m http.server 8000` and open `http://localhost:8000`.

## Project files

- `index.html` — English clinical learning content and expandable topic sections.
- `style.css` — responsive layout and topic-card styling.
- `app.js` — navigation, topic search, medication filtering, and current year.

## Content scope

The resource covers Parkinson’s disease foundations, motor and non-motor manifestations, history-taking and examination technique, differential diagnosis, medication mechanisms, complications, multidisciplinary roles, professional references, and glass-effect profile cards for the group supervisors and website creator. Topics are organized into expandable cards for easier navigation.

The active site is intended for professional education. It does not include patient intake, patient records, care-plan forms, individualized advice, or patient-facing handouts. Clinical content is educational and is not a diagnostic service, prescribing protocol, or substitute for supervised training, current local guidance, or clinical judgment.
